# Выплаты

Учёт выплат рабочим в цеху: сколько кому заплатили за день и сколько вышло за месяц.
Одна страница, без сборки, без сервера, без регистрации. Открывать с телефона.

Рассчитано на 25–30 работников: ~500 записей в месяц.

## Как пользоваться

1. **Быстрый ввод за день** — основной вечерний сценарий. Выбираешь дату (по умолчанию сегодня),
   получаешь список всех работников; напротив тех, кто работал, вписываешь сумму, остальных
   пропускаешь. У заполненной строки появляется поле комментария. Внизу липнет кнопка
   «Записать» со счётчиком: сколько выплат и на какую сумму уйдёт в базу.
   Кто уже записан за этот день — помечен серым, повторно его не внесёшь.
   Кто не получал выплат больше 60 дней, прячется под «Показать всех».
2. **Добавить выплату** — одиночная запись: имя (подсказки из уже введённых имён),
   сумма, дата, комментарий. Здесь же добавляется новый работник — после первой выплаты
   он появится в быстром вводе.
3. **Итоги по месяцам** — стрелки ‹ › или само поле месяца. Ниже: сумма по каждому работнику,
   общая сумма за месяц и записи месяца, свёрнутые по дням (в шапке дня — сколько человек
   и сколько денег). Тап по работнику в итогах оставляет внизу только его выплаты,
   «Показать всех» — снимает фильтр. Крестик удаляет ошибочную запись, с подтверждением.

Имена сравниваются без учёта регистра: «Ерлан» и «ерлан» — один работник.

## Данные

Всё лежит в `localStorage` браузера под ключом `wages-v1` — сохраняется между заходами,
но привязано к конкретному браузеру и телефону. Год работы цеха на 28 человек — около 560 КБ
при лимите порядка 5 МБ. Резервная копия:

```js
// в консоли браузера
copy(localStorage.getItem('wages-v1'))                 // выгрузить
localStorage.setItem('wages-v1', '<вставить json>')    // восстановить
```

Срок, после которого работник считается неактивным, — константа `RECENT_DAYS` в начале `app.js`.

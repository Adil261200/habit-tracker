# Выплаты

Учёт выплат рабочим в цеху: сколько кому заплатили за день и сколько вышло за месяц.
Одна страница, без сборки, без сервера, без регистрации. Открывать с телефона.

## Как пользоваться

1. **Добавить выплату** — имя (подсказки из уже введённых имён, новое имя можно просто вписать),
   сумма в тенге, дата (по умолчанию сегодня), при желании комментарий — что делал в этот день.
   После «Записать» список внизу сразу переключается на месяц этой записи.
2. **Итоги по месяцам** — стрелки ‹ › или само поле месяца. Ниже: сумма по каждому работнику,
   общая сумма за месяц и все записи месяца. Крестик справа удаляет ошибочную запись (с подтверждением).

Имена сравниваются без учёта регистра: «Ерлан» и «ерлан» — один работник.

## Данные

Всё лежит в `localStorage` браузера под ключом `wages-v1` — сохраняется между заходами,
но привязано к конкретному браузеру и телефону. Резервная копия:

```js
// в консоли браузера
copy(localStorage.getItem('wages-v1'))                 // выгрузить
localStorage.setItem('wages-v1', '<вставить json>')    // восстановить
```

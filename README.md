# Трекер

Личная одностраничная веб-страница: привычки, вес, kaizen-заметки. Без сборки, без зависимостей, без сервера.

## Запуск

Открыть `index.html` в браузере (двойной клик). Либо, если браузер капризничает с `file://`:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Что внутри

1. **Сегодня** — английский, силовая (активна только пн/ср/пт, в остальные дни «отдых»), счётчик Pomodoro. Ниже — история за последние 14 дней.
2. **Вес** — одна запись на неделю (повторная за ту же неделю перезаписывает предыдущую). График: пунктир — план 79 → 75 кг за 8 недель, сплошная линия — факт. Дата старта программы задаётся внизу карточки; от неё считаются номера недель.
3. **Kaizen** — заметка с автоматической датой (Ctrl/Cmd+Enter — сохранить), список ниже, наведение на заметку показывает крестик удаления.

## Данные

Всё лежит в `localStorage` браузера под ключом `habit-tracker-v1` — сохраняется между заходами, но привязано к конкретному браузеру и профилю. Резервная копия:

```js
// в консоли браузера
copy(localStorage.getItem('habit-tracker-v1'))                 // выгрузить
localStorage.setItem('habit-tracker-v1', '<вставить json>')    // восстановить
```

Параметры программы (79 → 75 кг, 8 недель, дни силовой) — константы в начале `app.js`.

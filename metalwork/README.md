# Сайт металлообрабатывающего производства

Одностраничный адаптивный сайт: шапка/hero, о компании, услуги (5 направлений),
портфолио, порядок работы, контакты с формой заявки.

## Что нужно заполнить

Все данные о бизнесе собраны в одном файле — **`config.js`**.
Больше нигде текст менять не нужно: значения подставляются на сайт автоматически.

Открыть `config.js` и заполнить:

| Поле | Что вписать |
|---|---|
| `company`, `companyShort` | Название компании (полное и короткое — для логотипа) |
| `city`, `region` | Город и география работы |
| `phoneDisplay` | Телефон в том виде, как его показывать |
| `phoneRaw` | Тот же телефон только цифрами — для кнопки «Позвонить» |
| `whatsapp` | Номер WhatsApp только цифрами, напр. `77001234567` |
| `telegram` | Username без `@`. Если пусто — кнопка Telegram скрывается |
| `email` | Необязательно. Если пусто — строка не показывается |
| `address`, `hours` | Адрес цеха и график работы |
| `years`, `aboutText` | Стаж и текст блока «О компании» |
| `facts` | Три плитки с цифрами в блоке «О компании» |
| `prices` | Цена по каждому из 5 направлений (или «Цена по запросу») |
| `steps` | Шаги блока «Как мы работаем» |
| `works` | Портфолио |

Пока поле не заполнено, на сайте вместо него видна заглушка ЗАГЛАВНЫМИ БУКВАМИ —
так сразу видно, что осталось дописать.

## Как добавить фото работ

1. Положить фото в папку `img/` (например `img/perila-1.jpg`).
2. В `config.js` в разделе `works` вписать имя файла:

```js
{ img: "img/perila-1.jpg", title: "Перила на лестницу, частный дом" },
```

Показываются только записи с заполненным `img`. Пока фото нет ни у одной,
раздел «Примеры работ» скрыт целиком вместе с пунктом меню — чтобы клиент
не видел пустые серые квадраты. Появится первое фото — раздел включится сам.

Оптимальный размер фото — примерно 1200×900 px, до 300 КБ.

### Фото должны быть свои

В портфолио идут только собственные объекты. Чужие снимки из интернета
брать нельзя: это чужая работа и чужие авторские права, а клиент, который
узнает объект или найдёт то же фото у другой фирмы, перестанет верить всему
остальному на сайте.

Снимать можно на телефон, этого достаточно:

- днём, при дневном свете, без вспышки;
- объект целиком плюс 1–2 кадра вблизи — сварной шов, полировка, крепление;
- горизонтальный кадр, объект в центре;
- прибрать инструмент и мусор из кадра;
- 8–12 хороших кадров с разных объектов лучше, чем 40 случайных.

## Форма заявки

Сайт статический, своего сервера нет, поэтому форма не отправляет письмо,
а собирает данные в готовое сообщение и открывает WhatsApp на номер из
`config.js` — клиенту остаётся нажать «Отправить». Для телефона это самый
короткий путь. Если нужна отправка на почту — можно подключить внешний
сервис форм (Formspree, Getform), это отдельная правка.

## Публикация на GitHub Pages

Settings → Pages → Source: ветка с сайтом, папка `/ (root)`.
Сайт будет доступен по адресу `https://<логин>.github.io/habit-tracker/metalwork/`.

## Локальный просмотр

Открыть `index.html` в браузере двойным кликом — этого достаточно.
